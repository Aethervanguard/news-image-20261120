## The image

`entry.png` is a 1024x1024 PNG (572,265 bytes) infographic summing up
Friday 20 November 2026 in six panels:

1. **Massive Russian strike on Kyiv** — 110 missiles, 400 drones, 8 killed;
   three bridges across the Dnipro hit (TOP STORY).
2. **Houthi missile hits Riyadh PIF Tower** — windows blown out on 7 floors
   of the Saudi sovereign wealth fund HQ, no injuries.
3. **World Court: Myanmar guilty of genocide** — the ICJ rules 9–6 that
   Myanmar committed genocide against the Rohingya.
4. **Global markets slide** — Nikkei −4.8%, SoftBank −16% as the AI
   sell-off spreads across Asia.
5. **Cyclone Akvan slams Odisha** — landfall near Gopalpur, 300,000 evacuated.
6. **Trump, Xi and Putin: Shenzhen declaration** — joint peace declaration
   from the first trilateral summit.

## Run

```sh
python3 main.py
```

Writes the image to `/output/entry.png`. The program only copies bytes
from `entry.png` in this repository: no network, no randomness, so repeated
runs produce byte-identical output.
