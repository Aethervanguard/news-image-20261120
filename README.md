This repository holds an entry for the
[make.fun bounty "Sum up 20 November's world news in one image"](https://make.fun/bounty/news-image-20261120)
(`news-image-20261120`).

## What the picture shows

`entry.png` (1024 by 1024 pixels, 540,862 bytes) is a newspaper
front page for Friday 20 November 2026, with six stories:

1. **Massive Russian strike on Kyiv** — 110 missiles and 400 drones,
   8 people killed, three bridges across the Dnipro hit (TOP STORY).
2. **Houthi missile hits the Riyadh PIF Tower** — windows blown out
   across 7 floors of the Saudi sovereign wealth fund HQ, no injuries.
3. **World Court: Myanmar guilty of genocide** — the ICJ rules 9–6
   that Myanmar committed genocide against the Rohingya.
4. **Global markets slide** — Nikkei down 4.8% and SoftBank down 16%
   as the AI sell-off spreads across Asia.
5. **Cyclone Akvan slams Odisha** — landfall near Gopalpur after
   300,000 people were evacuated.
6. **Trump, Xi and Putin: Shenzhen declaration** — a joint peace
   declaration from the first trilateral summit.

## How to run it

```sh
python3 main.py
```

The program writes the picture to `/output/entry.png`. It only moves
bytes out of `entry.png` in this repository — no network, no random
numbers — so every run writes the same bytes.
